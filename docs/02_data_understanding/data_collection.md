# Pengumpulan Data

Sumber acuan adalah Laporan Akhir Investigasi KNKT Nomor KNKT.26.04.03.02. Dataset kerja direncanakan berasal dari tabel/rekaman Data Logger yang diekstrak dari dokumen tersebut.

Metode ekstraksi, halaman sumber, rentang waktu, jumlah baris/kolom, dan checksum harus dicatat setelah berkas hasil ekstraksi tersedia. Jangan menyatakan skema 16 kolom tervalidasi sebelum pemeriksaan CSV/XLSX aktual.
