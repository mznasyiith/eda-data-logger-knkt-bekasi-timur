# Kamus Data

Kamus data final belum dapat ditetapkan sebelum dataset aktual diperiksa. Untuk setiap kolom, dokumentasikan:
- nama kolom asli dan nama baku;
- definisi serta satuan;
- tipe data dan contoh nilai;
- aturan nilai kosong/simbol khusus;
- sumber halaman/tabel;
- transformasi yang diterapkan.
