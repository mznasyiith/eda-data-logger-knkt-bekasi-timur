# Rencana Pemeriksaan Kualitas Data

Pemeriksaan minimum setelah dataset tersedia:
1. Pastikan format, encoding, delimiter, header, dan jumlah kolom.
2. Bandingkan jumlah baris dengan sumber dan catat rentang waktu.
3. Periksa duplikasi, nilai kosong, simbol khusus, dan konsistensi timestamp.
4. Verifikasi tipe data serta satuan tiap kolom.
5. Cocokkan sampel baris dengan halaman/tabel sumber.
6. Simpan hasil validasi tanpa mengubah file mentah.

Jumlah 16 kolom merupakan target pemeriksaan, bukan fakta tervalidasi sebelum file aktual diperiksa.
