# Struktur Proyek

- `data/`: data lokal, tidak di-commit.
- `docs/`: dokumentasi masalah, data, metodologi, keputusan, dan panduan.
- `notebooks/`: urutan analisis eksploratif.
- `src/eda_knkt/`: fungsi Python yang dapat diuji ulang.
- `tests/`: pengujian otomatis.
- `outputs/`: hasil visualisasi dan tabel lokal.
- `reports/`: laporan akademik dan teknis.
