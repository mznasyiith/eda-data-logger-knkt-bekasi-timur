# Reproducibility

- Gunakan versi Python dan dependensi yang dicatat.
- Simpan data sumber lokal pada `data/raw/` dan jangan commit.
- Jalankan notebook dari urutan yang ditetapkan.
- Hindari path absolut dan dependensi pada file lokal tersembunyi.
- Catat parameter, asumsi, serta keputusan pembersihan.
- Jalankan `pytest` setelah perubahan kode.
