# Pernyataan Masalah

Proyek ini mengeksplorasi rekaman Data Logger yang dirujuk dalam laporan investigasi KNKT Nomor KNKT.26.04.03.02. Analisis bertujuan memahami struktur, kualitas, pola, dan keterbatasan data sebagai dasar penyusunan temuan deskriptif.

EDA tidak dimaksudkan untuk menggantikan investigasi KNKT atau menetapkan sebab-akibat maupun tanggung jawab pihak tertentu.
