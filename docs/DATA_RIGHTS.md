# Kebijakan Hak Data

Repository ini memuat kode, dokumentasi orisinal, dan CSV transkripsi manual dari tabel pada Laporan Akhir Investigasi KNKT Nomor KNKT.26.04.03.02. PDF sumber dan workbook transkripsi per sumber tidak disertakan dalam repository pada saat audit ini. Keberadaan CSV transkripsi tidak berarti repository mendistribusikan ulang PDF sumber.

- Jangan mengunggah PDF sumber atau workbook lengkap sebelum hak distribusi dan ketentuan penggunaan dipastikan.
- Jangan menganggap dokumen yang dapat diakses publik otomatis bebas untuk didistribusikan ulang.
- CSV di `data/processed/data_logger_knkt_tabel_6_10.csv` adalah transkripsi manual untuk kepentingan analisis akademik; rujuk sumber KNKT dan jelaskan metode transkripsi.
- Catat nama sumber, nomor laporan, halaman/tabel, tanggal akses, metode ekstraksi, versi dataset, dan checksum SHA-256 bila relevan.
- Jangan mengubah data sumber tanpa bukti koreksi. Simpan provenance setiap koreksi.
- Gunakan data sintetis untuk pengujian yang dibagikan secara publik apabila distribusi data transkripsi tidak sesuai dengan ketentuan yang berlaku.
- Lisensi MIT repository tidak melisensikan ulang materi pihak ketiga.
