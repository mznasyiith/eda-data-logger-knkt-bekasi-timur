# Kebijakan Hak Data

Repository ini memuat kode dan dokumentasi orisinal. Laporan KNKT dan dataset hasil ekstraksi tidak disertakan karena hak akses dan distribusi ulang perlu dipastikan secara terpisah.

- Jangan mengunggah PDF sumber atau salinan tabel sebelum izin/hak distribusi dipastikan.
- Jangan menganggap dokumen yang dapat diakses publik otomatis bebas untuk didistribusikan ulang.
- Simpan data lokal di `data/raw/`; jangan menghapus atau mengubah berkas sumber.
- Catat nama sumber, versi, halaman/tabel, tanggal akses, metode ekstraksi, dan checksum bila relevan.
- Gunakan data sintetis untuk pengujian yang dibagikan secara publik.
- Lisensi MIT repository tidak melisensikan ulang materi pihak ketiga.
