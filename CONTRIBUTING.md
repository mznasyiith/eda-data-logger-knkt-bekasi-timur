# Panduan Kontribusi

1. Baca README dan `docs/DATA_RIGHTS.md`.
2. Jangan commit PDF KNKT, dataset mentah, data pribadi, token, atau kredensial.
3. Pertahankan data mentah; lakukan pembersihan pada salinan.
4. Catat keputusan transformasi dan asumsi pada `docs/decisions/`.
5. Jalankan `pytest` sebelum mengajukan perubahan.
6. Pastikan notebook dapat dijalankan ulang dan tidak bergantung pada path lokal absolut.

Gunakan branch terpisah dan Pull Request untuk perubahan substantif.
